# Football Fixtures

A react for searching football teams viewing their next fixutres or past matches. Also the possiblity to add favorites.



## How to run

Requirements Node.js 18 or newer.

    1. Clone the GitHub repository and go into the project folder.

        "https://github.com/Tudeee16/football-fixtures"

    2. Install the depencies
        "npm install"

    3. Start the development server:

        "npm run dev"

    4. Open the address shown in terminal.
